# 为了雷菌 · ForLeiJun

一个魔兽世界正式服插件，只回答一个问题：**这周哪几个金币世界任务最值钱？**

按「走法」排好序，点一行就在地图上标出路点；附带每张图特别任务的解锁状态（★可做 · ✓本周已完成），和附近没拍卖师时也能查的物价快照。

名字是为了攒钱买那只新出的雷龙坐骑（孢须真菌行者）——叫顺口了，就成了插件名。

---

## 它解决什么问题

金币世界任务的钱是**按角色算的**：你有十个号，理论上就是十份钱。

但一次只能登录一个角色。手动切号看地图，看到第五个号的时候，前面四个已经忘了。

这个插件把账号下所有角色的金币世界任务汇总成一屏：哪张图、什么任务、多少金、顺路还能带哪几个、快过期的先跑哪个。

## 为什么不按金额排

因为一趟出门从来不止办一件事。顺路任务的真实成本只有任务本身的时间，跨图的任务等于再开一趟行程。

还有一层：同一张图做够三个世界任务会解锁特别任务（约 2000 金宝箱），所以**同图扎堆**本身就是收益。

## 安装

1. 下载 `ForLeiJun-<版本>.zip`（在右侧 Releases 里），或者点 Code → Download ZIP 后解压
2. 把 `ForLeiJun` 文件夹整个放进：
   ```
   World of Warcraft/_retail_/Interface/AddOns/
   ```
3. 重启客户端，或 `/reload`

装完游戏里输入 `/lj` 就能打开。

**开箱即用**：无设置向导，无任何依赖插件，路点用暴雪自带标记（不需要 TomTom）。

## 命令

| 命令              | 作用                                    |
| --------------- | ------------------------------------- |
| `/lj` 或 `/雷菌`   | 打开主面板                                 |
| `/lj goal <金额>` | 改攒钱目标（支持 `5000000` / `500w` / `500万`） |
| `/lj ah <关键词>`  | 查拍卖行快照（如 `/lj ah 附魔`）                 |
| `/lj pin route` | 开关路线置顶窗                               |
| `/lj pin off`   | 全部关掉                                  |

## 数据口径

- 金币数来自游戏客户端的任务奖励字段，**不联网、不上传**，只写本地 `SavedVariables`（`ForLeiJunDB`）
- 面板标注「任务实发，不含掉落」——只算任务给的，不算打怪捡的
- 不同等级的角色看到的金币数不同，属正常现象
- 偶尔读到 0（任务刚刷新 / 刚 `/reload`）：按「不知道」处理，不进推荐——宁可漏，不可错
- 拍卖行价格是快照，标注采集时间，隔几小时只当参考价

## 兼容性

- **Interface**: `120105`, `120100`（正式服 12.1 系列）
- 纯原生 Frame 绘制，无自定义材质与字体，无第三方库依赖
